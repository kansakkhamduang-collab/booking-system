# ระบบจองคิวนิเทศออนไลน์

เว็บไซต์ PHP + HTML + CSS + Bootstrap + JavaScript สำหรับให้นักศึกษาจองคิวนิเทศออนไลน์กับอาจารย์

## โครงสร้างไฟล์

- `index.php` หน้าหลักแสดงปฏิทินและปุ่มจองคิว
- `api/bookings.php` API สำหรับดึงและบันทึกข้อมูลการจอง
- `db.php` เชื่อมต่อฐานข้อมูล และจัดการข้อมูลการจอง
- `config.php` ตั้งค่าการเชื่อมต่อฐานข้อมูล
- `schema.sql` สคริปต์สร้างตารางตามที่กำหนด
- `assets/css/style.css` กำหนดสไตล์หน้าเว็บ
- `assets/js/app.js` จัดการปฏิทินและฟอร์มการจอง

## การติดตั้ง

1. สร้างฐานข้อมูล MySQL และรันสคริปต์ `schema.sql`
2. เปิดไฟล์ `config.php` และปรับค่า DB_HOST, DB_NAME, DB_USER, DB_PASS ให้ถูกต้อง
3. รันเว็บเซิร์ฟเวอร์ PHP:

```bash
php -S localhost:8000
```

4. เปิดใช้งานที่ `http://localhost:8000`

## ตัวอย่างการใช้งาน

- คลิกปุ่ม `จองคิว`
- กรอกรหัสนักศึกษา ชื่อ-นามสกุล วันเวลา และรายละเอียด
- เลือก `รอบ 1` หรือ `รอบ 2`
- บันทึกข้อมูล ระบบจะตรวจสอบเวลาที่ทับซ้อนกัน และแสดงบนปฏิทินแบบ real-time
